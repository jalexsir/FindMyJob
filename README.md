# Deftech Jobs Bot

Telegram-бот з однією кнопкою "Переглянути вакансії" — збирає актуальні
вакансії з RSS-фідів DOU та Djinni за наперед налаштованими фільтрами
(DefTech / miltech, місто Івано-Франківськ).

## Встановлення (PyCharm)

1. Відкрий цю папку як проєкт у PyCharm.
2. Створи віртуальне середовище (PyCharm зазвичай пропонує це автоматично
   при відкритті проєкту з `requirements.txt`), або вручну:
   ```
   python -m venv .venv
   ```
3. Встанови залежності:
   ```
   pip install -r requirements.txt
   ```
4. Створи токен бота:
   - Напиши [@BotFather](https://t.me/BotFather) у Telegram
   - Команда `/newbot`, дай назву — отримаєш токен виду `123456:ABC-DEF...`
5. Скопіюй `.env.example` у `.env` і встав туди свій токен:
   ```
   cp .env.example .env
   ```
6. Запусти бота:
   ```
   python bot.py
   ```
7. Напиши своєму боту `/start` у Telegram — з'явиться кнопка.

## Структура проєкту

- `bot.py` — логіка Telegram-бота (кнопка, обробники)
- `feeds.py` — RSS-джерела та їх фільтри (тут легко додати нове джерело)
- `requirements.txt` — залежності
- `.env.example` — приклад файлу з токеном (сам `.env` не комітиться)

## Як додати нове джерело вакансій

Відкрий `feeds.py`, додай новий запис у словник `FEEDS`:

```python
FEEDS = {
    "DOU (DefTech)": "...",
    "Djinni (miltech)": "...",
    "Нове джерело": "https://example.com/rss/?фільтр=...",
}
```

## Плани на майбутнє (не в MVP)

- Розгортання на постійному хостингу (VPS)
